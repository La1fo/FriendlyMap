# FriendlyMap Menu Visual Pack

SVG-иллюстрации для основных разделов бота в едином стиле (белый + светло-голубой).

## Секции
- `main_menu.svg`
- `profile.svg`
- `achievements.svg`
- `leaderboard.svg`
- `faq.svg`
- `moderation.svg`

## Метаданные
- `manifest.json` — соответствие `section -> title/description/asset`.

Файлы рассчитаны на формат баннера `1200x630`, чтобы их можно было использовать как карточки в Telegram/WebApp.
